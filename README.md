## File Management
The File Management submenu now supports:
- Search by extension: PDF, DOCX, TXT, XLSX, CSV, etc.
- Search by filename/pattern
- Copy all matching files by extension
- Move all matching files by extension
- Rename files by extension
- Delete files by extension with confirmation
- Copy one file
- Move one file
- Rename one file
- Delete one file
- Folder listing
- File properties/details
- Open file
- Open folder

## Other modules
Backup, scheduled backup, ZIP/7-Zip, networking, system administration,
processes/services, Task Scheduler, environment variables, builds/tests,
Git, database CLIs, printers, disk management, maintenance, logs,
PDF/document processing, FFmpeg, remote administration, security auditing,
and system reports.

## Optional external tools
The corresponding menu entries use these programs when installed:
- Git
- Python
- Java
- MySQL
- SQL Server `sqlcmd`
- PostgreSQL `psql`
- SQLite3
- 7-Zip `7z`
- LibreOffice `soffice`
- Pandoc
- FFmpeg / FFprobe

The main application itself is Windows CMD/BAT and does not require those optional programs unless you use their functions.

## Permissions
Some Windows administration operations require an elevated Command Prompt.
Remote administration is intended only for systems you are authorized to administer.

Review destructive operations carefully.
